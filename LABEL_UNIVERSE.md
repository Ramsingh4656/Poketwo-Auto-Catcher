# Label Universe Decision

## Authoritative deployed universe

The deployed live system uses the 936 labels in `model/poketwo_detector_full/metadata.json`. This ONNX metadata is the authoritative source because the deployed visual model can emit only those 936 class indices. The generated `model/index_to_pokemon.json` is now an index-preserving copy of that metadata label array, with keys `0` through `935`.

This is a deployment snapshot, not a promise that it contains every current Pokétwo form. Its provenance is the committed ONNX export and metadata generated by the repository's full-coverage pipeline. When the ONNX model is retrained or replaced, the mapping must be regenerated and the class-count check must pass before deployment.

## Why the live hint resolver is scoped to 936 labels

A hint resolver that returns a label outside the visual model's universe can produce a name the deployed detector can never predict and can create inconsistent behavior between image and hint paths. The live resolver therefore searches the same 936-label mapping used by the ONNX detector. It returns a result only when exactly one authoritative label matches the normalized hint; ambiguous and unmatched hints abstain.

## Experimental hybrid universe

`archive/experimental_hybrid/model/index_to_pokemon.json` remains a separate 1,659-class mapping for the optional TFLite/pHash experiment. The hybrid path is not wired into `bot/` and is not part of the deployed live-system accuracy claims. Its resolver now searches the complete 1,659-class experimental mapping rather than only CNN top-five candidates. The hybrid mapping must not be mixed with the 936-class ONNX mapping without retraining/exporting a model against the same label order.

## Interim visual threshold

The live bot uses `CNN_CONFIDENCE_THRESHOLD=0.85` by default, with an environment override. The prior `0.30` value was based on the training/evaluation pipeline rather than a directly verified deployed ONNX calibration and was unsafe as an unconditional catch gate. Stage 6 should calibrate the deployed artifact on a representative held-out spawn set and replace this interim value with a measured operating point that explicitly balances false catches and abstentions.
